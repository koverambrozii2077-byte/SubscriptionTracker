## Цель работы

Закрепить навыки объектно-ориентированного программирования, работы со стандартной библиотекой STL, файлового ввода-вывода, проектирования модульных приложений и обработки пользовательского ввода в среде C++.

## Постановка задачи

- Реализовать полноценное CRUD-приложение для управления регулярными подписками и автоматическими платежами.
- Обеспечить поиск, фильтрацию и сортировку записей по различным критериям.
- Рассчитывать аналитические показатели: суммарные расходы, ближайшие платежи, топ категорий.
- Реализовать автозагрузку и ручное сохранение данных в текстовый файл.
- Создать удобное консольное меню с обработкой ошибок ввода.

## Функциональные возможности

### Управление данными (CRUD)
- Добавление подписки с уникальным идентификатором
- Редактирование существующей записи
- Удаление подписки по ID или названию сервиса
- Валидация входных данных (стоимость > 0, корректная дата, непустые строки)

### Поиск и фильтрация
- По названию сервиса (частичное совпадение, регистронезависимо)
- По категории (Развлечения, Софт, Обучение, Коммунальные, Другое)
- По диапазону стоимости
- По диапазону даты следующего платежа

### Сортировка
- По месячной стоимости (возрастание/убывание)
- По дате следующего платежа
- По алфавиту (название сервиса)

### Аналитика
- Суммарные ежемесячные расходы по всем активным подпискам
- Список подписок с датой оплаты в ближайшие 7 дней
- Топ-3 категории по суммарной стоимости активных подписок

### Работа с файлами
- Автоматическая загрузка `data/subscriptions.txt` при старте
- Ручное сохранение изменений по команде пользователя
- Формат строки: `id,service_name,category,monthly_cost,billing_cycle,next_payment_date,status`

## Установка и запуск

### Требования

- Компилятор с поддержкой C++17 (GCC >= 7, MSVC >= 2017, Clang >= 5)
- CMake >= 3.10 (опционально, если собирать через CMake)
- Git (для клонирования репозитория)

### Вариант 1: Сборка через CMake (рекомендуется)

```bash
# Клонирование репозитория
git clone https://github.com/koverambrozii2077-byte/SubscriptionTracker
cd SubscriptionTracker

# Создание папки для сборки
mkdir build && cd build

# Генерация файлов сборки
cmake ..

# Компиляция
cmake --build .

# Запуск (Windows)
cd Debug && SubscriptionTracker.exe

# Запуск (Linux/Mac)
./SubscriptionTracker
```

### Вариант 2: Сборка через компилятор вручную

```bash
# Клонирование репозитория
git clone https://github.com/koverambrozii2077-byte/SubscriptionTracker
cd SubscriptionTracker

# Компиляция всех исходных файлов
g++ -std=c++17 src/*.cpp -o SubscriptionTracker

# Запуск
./SubscriptionTracker
```

### Вариант 3: Microsoft Visual Studio

1. Откройте Visual Studio
2. Файл -> Создать -> Проект -> Консольное приложение C++
3. Назовите проект `SubscriptionTracker`
4. Добавьте все файлы из папки `src/` в проект:
   - ПКМ по "Файлы исходного кода" -> Добавить -> Существующий элемент -> Выберите все `.cpp`
   - ПКМ по "Заголовочные файлы" -> Добавить -> Существующий элемент -> Выберите все `.h`
5. Настройте свойства проекта:
   - C/C++ -> Язык -> Стандарт языка C++: `ISO C++17 Standard (/std:c++17)`
   - C/C++ -> Препроцессор -> Определения препроцессора: Добавьте `_CRT_SECURE_NO_WARNINGS`
   - C/C++ -> Командная строка -> Дополнительные параметры: `/utf-8`
   - Отладка -> Рабочий каталог: `$(ProjectDir)`
6. Соберите проект (Ctrl+Shift+B) и запустите (F5)

> **Примечание:** При первом запуске программа автоматически создаст папку `data/` и файл `subscriptions.txt` с примерами подписок, если они отсутствуют.
